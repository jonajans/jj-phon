# Jonathan Jansson's Phonetics Scripts

I do not like doing unnecessary work. In order to save myself from having to do precisely that, I have written a few [Praat](http://praat.org) and Python scripts through my phonetics studies which are collected here.

## Python

### PIA - Prosogram Interval Analyzer

`prosogram_interval_analyzer.py` (PIA) can be used to go from a list of (pitch, time) points as output by the [Prosogram stylization method](https://sites.google.com/site/prosogram/), to a csv containing the intervals between all of these points as well as lots of related information, to histograms over the distribution of intervals in the stylization. The script expects the Praat script files for Prosogram to be placed in a subdirectory called `plugin_prosogram`, in the same directory as the script. The aim was to have one script to go all the way from sound to histogram over the analyzed intervals, so a large portion of the code is concerned with generating the histograms, but they could of course be produced externally using the analysis result. Uses [Parselmouth](https://parselmouth.readthedocs.io/en/stable/) to run Prosogram through Python. Also has a CLI mode where either a .wav file or *_styl.txt-file can be provided. Wav file will be stylized, existing stylization will be analyzed. No arguments runs interactively. NB - the script has little error handling, and may crash in confusing ways if used in creative ways.


## Praat scripts

### Miscellaneous
`silenceZero` uses a reference TextGrid and silences all unlabeled intervals in the corresponding wav files by setting the selection to zero at the nearest zero-crossings. Intervals with labels are left untouched. I used it to silence sloppy field recordings were the researcher was heard just as well as the informant, but the informant's speech was at least labeled.

### SweDia 2000 scripts

The following scripts were written for correcting, extracting and conducting measurements on the word accents of Swedish in recordings from the [SweDia 2000 database](https://swedia.ling.gu.se/) (see Eriksson [2004](https://gupea.ub.gu.se/bitstream/handle/2077/23896/gupea_2077_23896_1.pdf?sequence=1) for a summary). Used for my Bachelor's thesis.

`fixTextGrids` corrects a common -- but predictable -- error in the annotation text grids of the SweDia prosody files, where the annotation meant for one interval has somehow ended up in the following interval instead. If a possible error is encountered, an editor window of the text grid and the associated .wav file is opened with the detected interval highlighted. The user is then given a range of options on if and how to perform an automatic correction. The corrected TextGrids are available for download in the 7z file. I only corrected the prosody files of the type 2 dialects and not the sections where compound words were elicited, and they are not perfect (but nevertheless more accurate than the raw SweDia annotation files).

`batchExtract` searches for a set of words present in the SweDia prosody material and, depending on if the match found has word accent 1 or 2, either extracts that word alone (accent 2) or extracts the matched word as well as the preceding word (accent 1), from both the text grid and it's matching .wav file. Presence of focus accent is determined based on the annotation. This script currently uses a .csv file provided with the SweDia research database to only extract from recordings of speakers of type 2-dialects but this could easily be bypassed.

`stylFallFinder` uses a text grid containing syllable segmentation (following the format of the one automatially generated by the Prosogram F0 stylization model) and another text containing orthographic word-level transcriptions to identify the interval of a recording in which a word accent fall is likely to occur. The fall is then identified and measured in the associated pitch tier file (as this is how Prosogram outputs it's stylizations). Depending on whether the identified word has word accent 1 or 2 (the latter of which is hard-coded based on words present in the SweDia material), different methods for identification are used. The script as it is written is only accurate for type 2A dialects following the Gårding dialect typology, but could easily be modified to fit other dialect types or measure other intonational phenomena.
